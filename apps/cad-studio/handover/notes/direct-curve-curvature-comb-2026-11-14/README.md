# D1268 — Show curvature combs on authored NURBS curves

2026-11-14 · FEATURE · P5, row 24 · [#537](https://github.com/barocss/barocss/issues/537) · [#2043](https://github.com/barocss/barocss/issues/2043)

Select one visible curve and choose **Show curvature comb** in the Direct geometry inspector. The comb and range use the current authored curve's native derivatives. The display connects tips only within each sampled knot span. Scale changes tooth length and leaves the measured values unchanged. The comb follows committed pole edits on the same curve and keeps its scale. Reverse creates a new selected curve, so enable the comb for the new object. Changing the selection or opening another document clears the old comb. A straight curve reports zero without teeth.

- **PASS, actual desktop Studio.** Opened a nonplanar rational quadratic with unequal weights and two unequal parameter spans. Selected it with a viewport click. Compared the comb at scales 4 and 8 mm². Reverse reflected the interior knot from −1 to 0 within the retained [−3, 2] domain. The new curve retained the same curvature and reversed the order of the spans. Changed the reversed curve's second pole from Z=7 to Z=9 mm in the inspector. The object ID and scale were stable, only the edited span's samples changed, and the measured minimum changed from 0.0224230956 to 0.0181625118 mm⁻¹. The straight control, same-ID document replacement and explicit Hide cleared the overlay as expected. The replacement moved the curve 6 mm along Y. Read-only inspection left the document unchanged.
- **PASS, independent geometry.** A Python oracle with exact rational Bernstein coefficients checked all 16 parameters, world positions and curvature vectors at each measured state. With three measured axes in the Iso/Ortho view, it compared every tooth endpoint and tip polyline against the projected 3D result. Maximum observed errors were 1.84e−15 mm for points, 7.05e−16 mm⁻¹ for curvature, and 2.68e−12 CSS px for projection. The oracle rejected stale source, dropped Z projection and a joined span. The four desktop screenshots were reviewed.
- **PASS, affected checks.** 13 focused Model tests, Model and Studio type checks, focused lint, driver syntax and Studio production build passed. The existing native B-rep edge comb also passed in desktop Studio with the existing local stdio MCP read. App.tsx is covered by the Studio type check and build. Its existing unused Sheet binding remains outside focused lint.
- **FAIL, intermediate.** The first desktop run failed the oracle's range check because a relative tolerance was tighter than the displayed seven-significant-digit value. The revised oracle checks the displayed rounding and independently checks unrounded native values. The full desktop flow passed afterward.
- **NOT_RUN.** Full suites, CI, mobile, paid live AI, separate WebGL2, live pole drag, Undo/Redo and surface curvature. This delivery measures the visible authored direct curve. The existing MCP tool still reads native shared B-rep edges. The wider issues remain open.
