# D2240 — Let the local Agent propose Rotate about an exact edge

P1, rows [04](../../roadmap-rows/04.md) and [31](../../roadmap-rows/31.md). Base `72c8ad5f1bb3b4c1c7e7092922e7f851cdcd9deb`. Continues [D2235](../native-edge-axis-rotate-2026-11-28/README.md) and the bounded rigid transform in [#629](https://github.com/barocss/cad/issues/629).

- **FAIL on the base.** A source-bundled Model run found the exact native edge on a 30 × 20 × 10 mm rectangular extrusion. Ordinary Rotate pivoted about the body centre, and explicit `values.about: 'edge'` was rejected before a proposal could be made.
- **Decision.** Share the native-line admission from the Studio menu with `features.command`. The local Agent reads a current `expectedRevision` from `query.rebuild` and an exact name from `query.summary`. It stages `command: 'rotate'`, `edges: [name]` and `values: { about: 'edge', angle }` under `proposals.propose`. This mode takes one unique straight native edge along world X, Y or Z on one standalone solid, with a finite signed angle of magnitude strictly between 0 and 360 degrees. Rotate persists the numeric pivot and axis. Ordinary Rotate retains its prior default, including calls that use an edge to select the body.
- **PASS, local stdio MCP at L1.** `describe` exposed the inputs. `query.summary` returned `n1.side0|n1.side1` at revision `6d1b3abd38708372`, from `[44.125, -3.75, 6.375]` to `[44.125, -3.75, 18.375]` mm. Six invalid proposals, direct mutation and direct acceptance were refused. The valid Tool call staged P1 and left the original nodes and output intact.
- **PASS, headed desktop Chrome.** Open the staged file. Preview and Hide keep the original document. Accept records explicit user approval and appends one original Rotate node at +30°. Undo restores the pending state. Redo, browser-project Save, Close, reload and Open restore the accepted result. The preview, hidden state, approved model and reopened model were reviewed as actual Studio captures. The source capsule included 1,300 files and the run recorded zero changes, page errors or downloads.
- **PASS, independent native result.** The eight vertices agree with the planar rotation matrix about the named edge within `1e-7` mm. Both endpoints remain fixed. Strict native validation confirms one closed solid with six faces, twelve edges and eight vertices. Volume is 9,600 mm³ and the centroid is `[21.804491924311225, -5.089745962155611, 12.375]` mm. The reopened properties and vertices match the accepted values.
- **PASS, feature checks with Node 22.19.0.** The Model filter `edge-rotate-agent toolset tool-contract proposals.test` passed 34 tests. The Studio filter `edge-rotation toolset-mcp tool-contract-mcp` passed seven. Both package type checks, changed-file ESLint, `git diff --check` and the Vite production build passed.
- **NOT_RUN.** Other native rotation fixtures in desktop Studio, general oblique/curved edges, placed parts, higher autonomy levels, live language-model execution, exchange, full local suites and mobile. #629 remains open for broader direct manipulation. The first mechanical CAD baseline remains 8/10.
