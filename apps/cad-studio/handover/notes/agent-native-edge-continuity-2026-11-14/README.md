# D1260 — Inspect native edge continuity from the CAD agent

2026-11-14 · FULL · P5, row 24 · [#537](https://github.com/barocss/barocss/issues/537) · [#2043](https://github.com/barocss/barocss/issues/2043)

Use `query.native_joints` with a base body key from `query.summary`. The action lists candidate shared edges and returns a SHA-256 revision of the admitted session document and exact body key. Pass that revision as `expectedRevision`, with the same body key and one listed `edgeId`, to `query.edge_continuity`. The action uses the Studio native reader and returns face identities, sample parameters, angles in degrees and both extrema. A stale revision, changed body, missing edge or unavailable native measurement produces a tool refusal without angle values. The two actions leave the document and viewport selection unchanged. The local MCP server uses its session document. Open a new session to read external file changes. Chat uses its captured turn document.

- **PASS, desktop Studio and real local stdio MCP.** Authored a 30 × 12 × 20 mm box with one R2 Fillet in Studio. The Studio inspector and MCP agreed on both straight joints with eight samples each. The largest absolute difference in displayed extrema was 7.197e−14° against a 1e−10° comparison limit. The independent plane–cylinder calculation gives 0° for both. Each MCP sample matched the direct native Model read exactly in Node. Both curved ends refused with `missing-pcurve`. The complete B-rep fingerprint remained equal to D1259.
- **PASS, revision and failure handling.** Another body and a changed extrusion refused the old revision. Rediscovery on the revised document allowed measurement with the new revision. Missing native ID `set_material` retained its literal spelling. An unresolved extrusion parameter returned a tool error. All three MCP sessions exited normally and retained the original input bytes.
- **PASS, desktop Chat.** With the actual Studio UI open, replayed the five real MCP tool responses through the local Chat transport and production summaries. The list, two measurements and two refusals appeared in the transcript. The authored document remained equal. External requests were blocked. All 1,124 frozen source files matched through Studio and cleanup.
- **PASS, focused checks.** 23 Model tests, Model and Studio type checks, scoped lint, generated tool docs, driver syntax and Vite build. Independent reviews covered native provenance and the public contract. The v2 list remains at 13 tools and 24,603 prompt/list characters of 25,000. Mutations that skip the revision check or omit the body from the revision each fail the targeted test.
- **FAIL, intermediate.** An exact comparison across runtimes rejected the first Studio/MCP run. The difference was 3.817e−14° on the first joint. The final check uses an absolute angular tolerance and retains exact MCP/Model assertions. Review also caught that evaluator exceptions could escape as JSON-RPC internal errors. The final Studio/MCP run confirms tool-level refusal with an absent parameter.
- **NOT_RUN.** Full suites, live LLM, mobile, general G2/G3, curved fillet end measurement and certification over a complete edge. Both GitHub issues remain open.
