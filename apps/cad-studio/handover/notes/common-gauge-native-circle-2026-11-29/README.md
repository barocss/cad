# D2254 — Preserve analytic native circles under common positive scaling

P2 [row 11](../../roadmap-rows/11.md) and [row 30](../../roadmap-rows/30.md) · [#772](https://github.com/barocss/cad/issues/772) · Base `b84df6380`.

- **FAIL, base.** The exact original R6 half-sheet with native knot break at 3 and domain [2,5] passes strict B-rep for both stored representations. The unit weights produce an analytic arc. Multiplying every weight by two leaves its native point and 25 mesh stations but emits 24 line segments in the independent SVG.
- **Decision.** Reuse the bounded common-gauge certificate from Projection commit `8f0b2b016`. Run the original recognizer first and keep its arithmetic. On refusal, a private candidate normalizes only a complete positive common weight gauge. The candidate checks all knot spans, plane, tangent and endpoint coefficients against the original input. Native controls, weights, knots and parameters remain untouched.
- **PASS, native and independent output.** The unit and doubled native sheets now have the same exact raw projection, one SVG analytic arc and byte-identical CPU PNG. The original unit raw, SVG and PNG also match the archived base byte for byte. The contour stays under real foreground cover. Unequal endpoint weights, noncircular and nonplanar coefficients, ordinary polynomial weights and incomplete spans remain outside the recognition. The native through-bore Boolean on the reweighted cylindrical solid passes strict and matches its analytic volume, 256π mm³.
- **PASS, actual desktop.** Headed Chrome opened a closed R6×8 mm cylinder carrying the complete doubled STEP coefficients. The user selected the analytic Top rim and placed Ø12 in Drawing. Project Save, Close, reload and fresh Open preserve the measured dimension, all original STEP weights and native B-rep, strict validity, and volume 288π mm³. The comparison uses the exact imported coefficient arrays for the two native half-cylinder representations.
- **NOT_RUN, current main.** The independent Projection worktree owns the full free-curve and clipped-curve paths. Current main's kernel API accepts B-reps and its native edge projection. The two independent package paths remain for integration, so #772 stays open. General rational reparameterization, ellipses and certified continuous visibility are outside this decision.
- **PASS, affected and full checks.** Node 22.19.0 passed 52 focused kernel and 29 Model Agent/Drawings cases. The full kernel suite reported 3335 pass, zero fail and 2 skip. Kernel, Model and Studio types, affected lint and Studio production build passed. The actual final desktop run retained 1,431 frozen source pins and no console errors.
