- **Decision.** Retain the original native knots and coefficients. Apply the existing quadratic station rule first. For a narrow set of compressed positive clamped Bézier spans with monotone projected controls, solve each requested position in the span's chord direction in the original parameter. The Bernstein scalar for any interior target changes coefficient sign once, so the positive rational coordinate has one root per target. The sampler keeps each full interior knot once, allows up to four spans and 64 intervals per span, and uses at most 64 bisections for each interior station. An unresolved or unsupported input retains the previous station route. Planar verification, its dense confirmation pass and tessellation use the same station rule. There is no general chord-error bound.
