# D1265 — Offset a solid face to a reference plane

2026-11-14 · FULL · P5, row 31 · [#2264](https://github.com/barocss/barocss/issues/2264) · [#536](https://github.com/barocss/barocss/issues/536)

In **Offset face**, choose **To plane** and pick a parallel face on another solid. The current native support plane sets the signed move. The History feature stores the selected face, the reference body and face identity, and a body-relative trim and signed plane witness. Moving the reference body updates the edited face. History can retarget the reference. The CAD agent can perform the same operation with `run_command`, two ordered face names, and `values.offsetMode = "to-plane"`.

- **PASS, actual desktop Studio.** Picked the wall of a convex hexagonal prism. A perpendicular face was refused with an actionable message. The opposite-facing reference wall moved the source face +1 mm. Editing the reference body's placement changed the same feature to −2 mm. Retargeting to the other parallel wall of the same reference body produced +3 mm and kept the feature ID. Undo, Redo, native Save, and fresh Open preserved the app result. Opening a separate collapse file retained the accepted part and showed the reason.
- **PASS, independent geometry.** The Python oracle used the supporting lines 4x − 3y = 77, 62 and 87, neighboring lines y = 0 and 4x + 3y = 120, and the shoelace formula. It verified native trim and chart points against the reference support over the three moves and the reopen. Volumes were 3934.791666666667, 3619.1666666666665 and 4093.125 mm³. The maximum observed support residual was 0 mm in these calculations. The native topology stayed at 8 faces, 18 edges and 12 vertices, with 36 parameter-curve bindings. The two face trims were 20 mm or more apart in Z. The unedited reference body retained its native digest when the source moved.
- **FAIL, intermediate.** Initial Model type-check found inferred union errors and the first focused fixture assumed a translated face gained a name prefix. Both were corrected. The first browser run observed the correct refusal in Kernel detail but found no useful message in the HUD. The final HUD explains the nonparallel selection. The first Studio type-check also found the old callback name in the Fillet hook test fixture.
- **PASS, affected checks.** 66 Model tests and 32 Studio tests pass. Model and Studio type-checks and the Studio build pass. Both signed-distance and parallel-guard mutations fail their tests as expected. Two independent reviews confirmed exact-prefix ownership and the reference witness. The changed Model, HUD, preview, viewport and test paths pass lint. Full-file App lint still reports an existing unused Sheet bend-table variable at the parent commit.
- **Limits.** To plane uses the existing direct native Offset face source path. It refuses a coincident plane, a tilted plane, a missing or changed named face and a move that collapses the solid. The chart and parallel tests are roundoff-sensitive. Extreme translations of very short reference walls can be refused. Placed-instance picks and duplication of a linked Offset body are outside this delivery. The Studio oracle covers the authored convex hexagonal prism. Wider face replacement, curved neighbors, full suites, paid live use and mobile are **NOT_RUN**. Both issues remain open.
