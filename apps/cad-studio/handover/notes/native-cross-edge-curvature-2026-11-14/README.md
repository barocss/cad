# D1262 — Measure sampled cross-edge curvature

2026-11-14 · FULL · P5, row 24 · [#537](https://github.com/barocss/barocss/issues/537) · [#2043](https://github.com/barocss/barocss/issues/2043)

The Studio Edge continuity inspector reports the maximum sampled normal-curvature difference in the direction across the native edge. The CAD agent can request the same result with `query.edge_continuity` and `curvature: true`. Each sample gives signed values in the order of the reported faces and their absolute difference, in inverse millimetres. Omitting the option or setting it to false returns the angle result alone.

The reader verifies the native edge and both bindings at the existing eight samples. If every oriented face-normal angle is at most 1e−7 radians, it builds a common transverse direction from the edge tangent and the mean normal. It projects the direction into each tangent plane and applies the native second derivatives in that chart. A sharp joint, unavailable derivative or ill-conditioned chart prevents a curvature result and retains the angle result when available. The maximum describes only the sampled direction and points.

- **PASS, actual desktop Studio and real local stdio MCP.** Studio authored a 30 × 12 × 20 mm box with one R2 Fillet and measured its two straight joins. The plane value was 0 mm⁻¹ and the convex cylinder value was −0.5 mm⁻¹ within 1e−10 mm⁻¹. The independent oracle uses the authored radius and the circle's arc-length acceleration. Studio reported 0.5 mm⁻¹ at both joins. MCP agreed within 1.111e−15 mm⁻¹ and matched the complete Model trace exactly in Node. The original 90° sharp rim retained its angle and refused curvature in Studio and MCP. Both curved ends still refused because their parameter curves were unavailable. Undo and Redo cleared the inspector. The native fingerprint matched D1259.
- **PASS, agent compatibility.** The real MCP server described the optional boolean field. Omitted and false requests returned the same angle payload. All four input files remained byte-identical. The desktop Chat panel replayed the real responses and showed both edge identities and the expected 0.5 mm⁻¹ value. The browser blocked external requests.
- **PASS, focused checks.** 31 kernel tests, 20 Model tests, kernel and app type checks, code shape, scoped lint, generated tool documentation and Vite build. The 13-tool list and prompt occupy 24,615 of 25,000 characters. Two independent reviews covered geometry and integration. Separate analytic probes checked oblique charts, varying curvature, direction and sense reversal, a C1 interior knot and an ill-conditioned chart. Skipping the tangency guard or omitting the mixed derivative makes the focused tests fail.
- **NOT_RUN.** Full suites, native Save/reopen, live LLM, mobile, curved-end measurement, general G2/G3 classification and complete-edge certification. Both linked issues remain open.
