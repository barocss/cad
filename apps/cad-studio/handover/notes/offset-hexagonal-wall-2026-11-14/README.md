# D1264 — Offset an oblique wall of a convex hexagonal prism

2026-11-14 · FULL · P5, row 31 · [#2264](https://github.com/barocss/barocss/issues/2264) · [#536](https://github.com/barocss/barocss/issues/536)

Select the oblique upright wall of a solid extruded along world Z from an authored, straight, convex six-point polygon. **Offset face** moves its support plane by a signed distance along its outward normal. The adjacent walls and both caps are trimmed again on their original planes. Face names, incidence, topology IDs and parameter-curve IDs remain stable. The change is one editable History feature.

- **PASS, desktop Studio.** The starting build refused the selected side with a cap-only message. The new build applies +1 mm, refuses −9.6 mm without changing the accepted feature or body, and accepts −2 mm in History. Undo and Redo restore the corresponding exact documents. Native Save and fresh Open reproduce the edited B-rep. Opening a file with a −9.6 mm edit keeps the current part and shows the refusal reason. The applied, refused and reopened states were also reviewed visually.
- **PASS, independent geometry.** For the 10 mm high fixture the selected plane is 4x − 3y = 72 + 5d, with signed distance d. The adjacent planes are y = 0 and 4x + 3y = 120. An independent Python oracle intersects the planes, checks finite face charts, and computes the section area with the shoelace formula. Studio and native volumes agree with 3934.791666666667 mm³ at +1 mm and 3619.1666666666665 mm³ at −2 mm. Maximum error against the independent volume was 2.274e−12 mm³ across the original and three edited reads. The largest plane residual was 3.553e−15 mm. Strict B-rep checking found one closed body with 8 faces, 18 edges, 12 vertices and 36 pcurves. The largest measured pcurve gap on these Studio files was 4.351e−15 mm.
- **PASS, affected checks.** Kernel and Model tests check both signs, exact collapse in both directions, native identity, stale face signatures, original retention and the shared agent command. Two independent source reviews checked native geometry and product routing. A separate native audit exercised 20 rotated, scaled, translated and height-varied combinations. Both the signed-intersection and collapse-guard mutations failed their tests as expected. The Kernel, Model and Studio type checks and the Studio production build pass.
- **FAIL, intermediate cold Part evaluation.** An initial candidate generated the source topology IDs under the Offset face feature ID when the input was first converted. The Offset face route now uses the target output ID for conversion and for the stored signature check. Cold and warm Part evaluations produce identical B-reps.
- **NOT_RUN.** Full test suites, CI, mobile, paid live models and wider direct-edit scope. The Studio flow covers one authored hexagonal extrusion. Curved neighbors, other polygon sizes, arbitrary face replacement and topology changes remain open.
