P1, rows [04](../../roadmap-rows/04.md) and [30](../../roadmap-rows/30.md). Base `f4870d818d4bb7b025989e537c55a9d3b3e1e2a4`. Bounded follow-up to [D2168](../four-opening-box-wall-shell-2026-11-28/README.md) and [#13](https://github.com/barocss/cad/issues/13).

- **FAIL on the base.** For the three opposite retained-wall pairs, the native producer emitted the correct bracketed message but exposed only the generic `CAPABILITY` code. The public refusal inventory omitted `SHELL_DISCONNECTED`. Its source audit also included seven lowercase unsupported reasons from B-rep continuity even though the bracketed-code parser only recognizes uppercase tokens.
- **Decision.** Register the existing Shell token in both public code lists. The Part error returns `SHELL_DISCONNECTED` as its code and retains `CAPABILITY` as `details.category`. Use the parser's uppercase token rule when auditing refusal unions in source. Lowercase continuity reasons retain their existing separate result contract. The Shell geometry and refusal condition are unchanged.
- **PASS, public native and Model.** All three opposite retained-wall pairs now carry the specific code and original category. The existing conditions for invalid ownership and collapse still refuse. Adjacent kept walls still build strict native geometry. Both registry audits and the refusal parsing check pass.
- **PASS, headed desktop Studio.** An original 40 × 30 × 20 mm box refuses opposite walls, disables Apply and keeps all 24,000 mm³. Cancel retains the stock. The adjacent-wall control produced 4,760 mm³, accepted the History edit to 7,720 mm³ and preserved it through Undo, Redo and project Save, Close, reload and Open. The reopened feature shows Front 8 mm and Left 3 mm. Actual desktop used a 1,299-file frozen capsule with no page errors, file deliveries or source changes.
