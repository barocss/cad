# D1267 — Display a native edge curvature comb

2026-11-14 · FULL for the read API · P5, row 24 · [#537](https://github.com/barocss/barocss/issues/537) · [#2043](https://github.com/barocss/barocss/issues/2043)

Select one native shared edge and use **Show curvature comb** in the Selection inspector. Eight sample parameters lie strictly inside each positive knot span. The native curve's second derivatives supply the points, magnitudes and world-space curvature vectors. Separate SVG polylines connect the tips within each span. The display scale in mm² multiplies those vectors to set lengths in mm. Changing it leaves the measured curvature in mm⁻¹ unchanged. Straight edges report zero without teeth. The comb is a foreground analysis overlay. It does not intercept picks.

The local agent reads the same native samples through `query.edge_curvature` using the edge ID and revision from `query.native_joints`. It returns world points, vectors, extrema and individual knot spans. It makes no document change and refuses a stale revision.

- **PASS, actual desktop Studio and local stdio MCP.** Selected the straight top rim and the R4 semicircular top rim through the viewport. The line reported 0 mm⁻¹. The arc reported 0.25 mm⁻¹ across 16 samples, eight on either side of its internal knot. Changing scale from 4 to 8 mm² changed tooth length from 1 to 2 mm. Hiding the comb and opening a taller document with reused native edge IDs cleared the old overlay. A new read measured the correct edge at Z=8 mm. The same two native readings were returned by MCP, and the old revision was refused on the taller part. Neither application modified its source or produced a download.
- **PASS, independent math.** For each arc sample, the oracle used the known center and radius to calculate the true vector as (center − point) / R². The largest vector residual was 4.108e−16 mm⁻¹. With the Top/Ortho view, the oracle compared the expected projected origins and tips with all rendered SVG line endpoints. The maximum residual was below 4.7e−13 CSS px. Both document states were reviewed visually.
- **PASS, source and build checks.** The 13 focused Model checks include reversed curve parameters and refusal for a mixed faceted body. Model and Studio type checks, focused ESLint, generated tool documentation and the Studio production build passed. The focused test rejected both an outward-vector mutation and a knot-sampling mutation.
- **FAIL, intermediate.** The first browser driver's projection check assumed identical horizontal and vertical pixel scales to within 1e−6 px on replacement. The actual camera projection differed by 2.372e−6 px per millimetre. The revised oracle uses both measured projection axes and checks each endpoint to 1e−6 px. The first aggregate tool-contract test also showed the new read was missing from its coverage inventory. The revised test invokes and validates the new action with the declared chat state type. The existing unused Sheet binding in App.tsx remains outside the focused lint command.
- **NOT_RUN.** Full suites, CI, mobile, paid live AI, separate WebGL2 execution, zoom/orbit and injected late worker replies. The comb covers one native shared edge at a time. Placed or merged picks and direct curves are outside this delivery. Display tips crossing a clip plane can hide their span. These are sampled values. Both wider issues remain open.
