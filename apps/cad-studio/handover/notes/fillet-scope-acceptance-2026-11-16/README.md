## Genuine tangent STEP boundary: OPEN, not a Fillet pass

An existing local fixture was identified rather than substituting the historical sharp lid: `circular-1024.step`, 8,945 bytes, SHA256 `3f2cc1b71923713941e34dfce461d1cd14dc07a1d66bc76137b9d5e0155b0953`, generated by `step-continuity-help-browser.mjs` from a 30×12×20 box with R2 on the front/top edge. At x=0…30,y=2,z=20 the top and blend share native edge `n0_e86` (`n0.n1.top|n0.n2.face`). Read-only source review finds the blend boundary derivative along X and its transverse derivative parallel to top plane z20; original native measurements additionally reported max normal angle 7.1968e−14 degrees. Imported missing-pcurve inspection remains a separate measurement limitation, not a non-tangent diagnosis.

Actual first attempt `/tmp/cad-step-tangent-audit01` could not pick that seam and timed out before Fillet. Investigation found the native edge exists but `engine/mesh.ts` intentionally excludes tangent joints from `DisplayEdge` (normal dot > cos(pi/9)). `commands.ts` resolves Edge Fillet from those display picks. A second characterization `/tmp/cad-step-tangent-boundary02` explicitly verifies one named native seam, absence from display picks, a real click leaving zero selection, and exact imported-document preservation. Strict B-rep and independent volume `7200−120(1−pi/4)` agree within1e−7 mm³. The screenshot was reviewed. This PASS is **only the selection-policy characterization; Fillet on the tangent seam remains NOT_RUN**. No bypass or injected selection was used.

A safe product change is not simply to remove the normal threshold: that alters global display-edge indices, picking, face-edge derivation, handles and finish inputs for unrelated commands. The existing native continuation code also deliberately avoids smooth joints because there is no corner there. Any future inspect-only native-seam selection must retain separate identities and must not silently authorize finishing or change the geometry policy. The original sharp-lid refusal is resolved, but the broader imported tangent-boundary workflow is not certified; keep #23 OPEN with this explicit remaining boundary. No threshold, topology or UI ownership redesign is made during this audit.
