**Current Chrome run: PASS.** The regression driver now expects the current straight-trim diagnostic (convex, 3–16 edges, no holes), not the historical rectangle-only text. It still picks the exact holed cap `n3.bottom` and checks that Apply stays disabled and the accepted model is unchanged. The same run refuses a nonparallel planar face and a curved cylinder side, then recovers by picking `n1.bottom`. The new native body has eight corners and the expected 2,000 mm³. Deletion review is non-mutating, Cancel retains the result, explicit deletion removes exactly the two dependent features, first Undo restores the relation, and first Redo restores the deletion. Eight actual Studio states, no runtime errors, and 1,235 source files unchanged through cleanup.

**Focused tests:** 53 Model cases selected by `face-end-extrude`, one Studio case selected by `extrude-end-face-pick`, browser driver syntax and diff checks. To replay the browser scenario, run [the driver](../../../test/extrude-end-face-refusals-browser.mjs) with the output directory, `D850_SOURCE_FROZEN=1`, `PW_DIR` and `CHROME`.
