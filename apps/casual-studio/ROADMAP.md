# Casual Studio 로드맵

[제품 원칙](PRODUCT.md) · [진행 이슈 #749](https://github.com/barocss/cad/issues/749)

**목표:** 기존 설계를 빠르게 내 상황에 맞추고, 전문 CAD에서 이어서 편집할 수 있는 파일을 남긴다. 한 번에 한 단계만 구현한다. 새 예제는 해당 단계의 완료 기준을 통과하기 전에는 시작 화면에 표시하지 않는다.

| 순서 | 상태 | 사용자가 끝낼 일 | 완료 기준 |
| --- | --- | --- | --- |
| 0. 독립 앱과 파일 왕복 | 완료 | 케이블 가이드 판 하나를 내 장비에 맞춰 수정한다. | 실제 형상으로 A만 Ø6→Ø8, B Ø6·간격 30 mm 유지. 미리보기·적용·Undo/Redo, 코드 없이 저장, CAD Studio 편집 후 Casual 재열기. |
| 1. 용도 중심 시작 화면 | 구현 완료 · 첫 사용자 검증 대기 | 첫 화면에서 케이블 가이드 예제를 골라 저장하거나 지원되는 내 파일을 연다. | 목적·결과·편집값을 보여주고 편집 중에는 예제 목록이 사라진다. 유효하지 않은 파일은 기존 모델을 바꾸지 않는다. 화면 전환 시 미적용 입력과 적용 후 미저장 변경을 구분해 보호한다. 실제 데스크톱·좁은 화면 브라우저로 확인한다. |
| 2. 센서 케이스 공유 치수 | 다음 | 폭이 다른 센서 보드를 기존 케이스에 끼운다. | 보드 폭 56→64 mm에 본체·뚜껑 64→72 mm, 오른쪽 고정점 두 곳 +8 mm. 왼쪽 고정점과 포트 크기는 유지. 근거 치수와 종속 부위를 표시하며, 단일 적용·Undo 및 native 파일 재열기에서 같은 공유 치수를 보존한다. |
| 3. 셀프센터링 바이스 | 대기 | 다른 폭의 부품을 물릴 수 있도록 두 조를 조정한다. | 조/베이스를 누르면 부품 옵션, 간격 치수를 누르면 조립 옵션이 열린다. 40→60 mm에서 양쪽 조는 −10/+10 mm 이동, 작업 중심과 베이스 고정홀 유지. 나사 동역학·제조 검증은 범위 밖. |

## 운영 기준

- 첫 사용자 검증: 사전 설명 없이 시작해 30초 안에 용도를 말하고 알맞은 예제를 선택하는지 관찰한다. 이어서 코드 없이 A만 바꿔 저장하도록 요청한다. 30초는 목표이며 현재 측정 결과가 아니다.
- 지원 파일이 무엇인지 먼저 보여준다. 지원하지 않는 구조는 Casual이 저장 형태를 바꾸지 않고 CAD Studio로 안내한다.
- 형상 치수 테스트와 실제 브라우저 경로의 결과를 이슈에 남긴다. 유지돼야 하는 치수도 같이 확인한다.
- 공통 커널과 native 파일만 공유한다. Casual 사용에 전문 CAD Studio 셸, 피처 트리, 상시 코드/채팅 패널을 요구하지 않는다. 배포와 범용 편집기 확장은 별도 범위다.
