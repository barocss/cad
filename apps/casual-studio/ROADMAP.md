# Casual Studio 로드맵

[제품 설계](PRODUCT.md) · [진행 이슈 #749](https://github.com/barocss/cad/issues/749)

**목표:** 작은 CAD 모델을 예제에서 수정하거나 빈 코드에서 만들고, 모양뿐 아니라 편집할 수 있는 결과를 남긴다. 사용자 흐름을 하나씩 끝낸다. 검증이 끝난 시작 경로와 예제만 사용자에게 노출한다.

| 순서 | 상태 | 사용자가 끝낼 일 | 완료 기준 |
| --- | --- | --- | --- |
| 0. 독립 앱과 CAD 파일 왕복 | 완료 | 케이블 가이드 판의 지름 하나를 수정한다. | 실제 형상으로 A만 Ø6→Ø8, B Ø6·간격 30 mm 유지. 미리보기·적용·Undo/Redo·저장 및 CAD Studio 편집 후 Casual 재열기. |
| 1. 예제/파일 시작 화면 | 구현 완료 · 첫 사용자 검증 대기 | 예제를 골라 편집하거나 지원되는 내 파일을 연다. | 목적·결과·편집값을 먼저 제공. 예제 목록은 편집 중 숨김. 잘못된 파일·전환 취소 시 작업 유지. 데스크톱·좁은 화면 검증. |
| 2. 빈 코드에서 새 모델 만들기 | 완료 | 기존 판에 의존하지 않고 코드를 쓰거나 붙여넣어 내 장착판을 만든다. | 빈 캔버스에서 판과 위치/지름이 서로 다른 관통 홀 3개를 생성. 틀린 코드나 겹침은 마지막 적용 모델을 유지한다. 원문을 다시 열고 편집한 뒤 `.bcad`를 내보내 CAD Studio에서 진짜 피처로 열어 확인한다. Chrome에서 실제 빈 시작, 지름 3종, 오류 후 마지막 모델 유지, 레시피 재열기 및 CAD Studio 피처 수정 확인. |
| 3. 캔버스 ↔ 코드 공개 치수 | 구현 완료 · 첫 사용자 검증 대기 | 예제와 새 코드 모델을 같은 편집 공간에서 고친다. | 공개 파라미터만 캔버스에 노출하고 변경 시 해당 선언만 수정. 주석·다른 선언·피처 ID 유지. 코드 편집으로 바꾼 값도 캔버스와 일치. 적용 한 번 및 Undo 한 번이 원문·모델에 동일하게 작동한다. 케이블 가이드 예제와 새 코드 모델이 같은 편집기를 쓴다. 예제 기본값 복원은 미리보기·적용을 거치고 한 번으로 Undo된다. 첫 사용자 두 흐름은 관찰 대기. |
| 4. 센서 케이스 공유 치수 | 데스크탑 검증 완료 · 시작 화면 제공 | 폭이 다른 보드에 맞게 케이스를 바꾼다. | 56→64 mm에서 본체·뚜껑 64→72 mm, 오른쪽 고정점 2개 +8 mm. 왼쪽 고정점과 포트 크기 유지. 변경 부위별 전후 수치와 캔버스 강조를 연결하고, 위에서 보이지 않는 변화도 숫자로 안내한다. 레시피 재열기 후 공유 관계가 살아 있고 CAD 출력도 실제 형상과 일치한다. |
| 5. 셀프센터링 바이스 | 데스크탑 검증 완료 · 시작 화면 제공 | 양쪽 조를 작업물 폭에 맞춘다. | 조/베이스 클릭은 부품 옵션, 간격 클릭은 조립 옵션. 40→60 mm에서 양쪽 조 −10/+10 mm, 작업 중심과 베이스 고정홀 유지. 나사의 동역학과 제조 검증은 범위 밖. |
| 6. 4륜 로버 조립 보기 | 데스크탑 검증 완료 · 시작 화면 제공 | 모델을 돌려 보고, 분해도와 조립 순서를 비교한다. | 25개 실형상, 4단계에서 추가 부품만 강조. 이전 단계로 돌아가면 대기 부품은 표시·선택하지 않는다. 원본 BCAD 바이트가 같고 CAD Studio에서 24개 배치와 저장 단계를 다시 연다. |

## 센서 케이스 구현 순서

1. **형상 완료.** [검증용 모델](examples/sensor-enclosure/README.md)에서 본체·뚜껑·보드와 고정점 네 개를 실제 CAD 솔리드로 만들었다. 56·60.5·64 mm를 측정했고 저장/재열기 이후에도 공유 입력이 유지된다.
2. **편집 완료.** 범위 안의 보드 폭 하나만 미리 보고 적용한다. 잘못된 치수나 취소는 Undo를 만들지 않는다. 미리보기에서 전후 값을 보여주고, 각 행을 포커스하면 관련 부품 또는 고정점이 강조된다.
3. **파일 검증 완료.** 데스크탑 Chrome에서 미리보기·적용·취소·Undo/Redo·레시피 재열기를 확인했다. 64 mm를 적용해 내보낸 CAD에서 72 mm 본체를 열고, 56 mm로 바꿔 64 mm 본체를 다시 계산했다. 시작 화면의 두 번째 예제로 제공한다.

**후속 백로그: 실제 PCB 연동.** 현재 예제의 단순화한 보드와 별개로, [CAD Studio의 PCB–케이스 연동 트랙](../cad-studio/handover/roadmap-tracks/03-platform-and-extensions.md#pcbenclosure-mechanical-fit-backlog)에서 KiCad 보드 가져오기 → 장착·뚜껑·포트 검사 → 개정 반영을 검증한다. [#756](https://github.com/barocss/cad/issues/756)이 통과한 뒤 Casual에서 실제 보드를 확인하는 예제를 검토한다. 지금 구현 순서는 바꾸지 않는다.

## 셀프센터링 바이스 구현 순서

1. **형상 완료.** [검증용 모델](examples/centering-vise/README.md)에서 40→60 mm일 때 실제 왼쪽 조 −10 mm, 오른쪽 조 +10 mm, 중심축과 베이스 고정홀 유지 및 CAD Studio 파일 재열기를 확인했다.
2. **편집·파일 완료.** 조를 클릭하면 선택한 그립 높이만 바뀌고, 간격선에서 바꾸면 양쪽 조가 함께 움직인다. 베이스는 고정 치수만 표시한다. 서로 독립적인 Undo/Redo, 저장과 재열기, CAD Studio에서 내보낸 간격 재계산을 데스크탑에서 확인했다. 시작 화면에서 사용할 수 있다.

## 다른 CAD에서 가져올 것

- **[OpenSCAD Customizer](https://en.wikibooks.org/wiki/OpenSCAD_User_Manual/Customizer#Syntax_support_for_generation_of_the_customization_form):** 선택한 값의 읽기 쉬운 이름·단위·허용 범위와 [기본값 복원](https://en.wikibooks.org/wiki/OpenSCAD_User_Manual/Customizer#GUI). 케이블 가이드의 복원은 반영했다. 치수 범위 표시를 센서 케이스에 확장하되 실제 형상에서 검증할 수 있는 제한만 보여준다. 복원도 검증·미리보기·적용을 거친다. 상시 설정 패널과 JSON 프리셋은 추가하지 않는다.
- **[Onshape Modeling In-Context](https://cad.onshape.com/help/Content/Assembly/modeling_in_context.htm):** 영향을 받는 부품 목록과 모델 강조를 연결한다. 센서 케이스에서 변경량이 적힌 짧은 목록을 두고, 마우스나 키보드 포커스로 해당 부품 또는 고정점을 표시한다. 외부 문서 참조·조립 컨텍스트 스냅샷은 도입하지 않는다.

각 단계에서 소스 테스트로 형상 치수와 고정값을 검증하고, 실제 데스크탑 브라우저에서 시작부터 저장까지 실행한다. 예제 사용자의 30초 목표는 직접 관찰하기 전까지 달성으로 표시하지 않는다.

## 조립 보기 검증 예제

[RoverKit](https://a2aprotocol.ai/tools/roverkit)의 조립/분해 및 단계별 강조를 참고해, [4륜 로버 검증 파일](examples/rover-assembly/README.md)을 실제 CAD Studio에서 만들었다. Casual에서는 **로버 조립 보기**로 이 원본을 열고, 캔버스 회전·분해와 네 순서를 확인한다. 화면 전용 분해 좌표와 선택 상태는 원본 CAD에 저장하지 않는다. 4단계에서 고른 센서가 3단계로 돌아가면 표시와 선택에서 함께 빠지는지 검증했다. 주행, 배선, 조립 편집은 범위 밖이다.
