# Casual Studio 로드맵

[제품 설계](PRODUCT.md) · [진행 이슈 #749](https://github.com/barocss/cad/issues/749)

**목표:** 작은 CAD 모델을 예제에서 수정하거나 빈 코드에서 만들고, 모양뿐 아니라 편집할 수 있는 결과를 남긴다. 사용자 흐름을 하나씩 끝낸다. 검증이 끝난 시작 경로와 예제만 사용자에게 노출한다.

| 순서 | 상태 | 사용자가 끝낼 일 | 완료 기준 |
| --- | --- | --- | --- |
| 0. 독립 앱과 CAD 파일 왕복 | 완료 | 케이블 가이드 판의 지름 하나를 수정한다. | 실제 형상으로 A만 Ø6→Ø8, B Ø6·간격 30 mm 유지. 미리보기·적용·Undo/Redo·저장 및 CAD Studio 편집 후 Casual 재열기. |
| 1. 예제/파일 시작 화면 | 구현 완료 · 첫 사용자 검증 대기 | 예제를 골라 편집하거나 지원되는 내 파일을 연다. | 목적·결과·편집값을 먼저 제공. 예제 목록은 편집 중 숨김. 잘못된 파일·전환 취소 시 작업 유지. 데스크톱·좁은 화면 검증. |
| 2. 빈 코드에서 새 모델 만들기 | 다음 | 기존 판에 의존하지 않고 코드를 쓰거나 붙여넣어 내 장착판을 만든다. | 빈 캔버스에서 판과 위치/지름이 서로 다른 관통 홀 3개를 생성. 틀린 코드나 겹침은 마지막 적용 모델을 유지한다. 원문을 다시 열고 편집한 뒤 `.bcad`를 내보내 CAD Studio에서 진짜 피처로 열어 확인한다. 이 경로를 완성할 때까지 시작 화면에 가짜 진입 버튼을 놓지 않는다. |
| 3. 캔버스 ↔ 코드 공개 치수 | 대기 | 예제와 새 코드 모델을 같은 편집 공간에서 고친다. | 공개 파라미터만 캔버스에 노출하고 변경 시 해당 선언만 수정. 주석·다른 선언·피처 ID 유지. 코드 편집으로 바꾼 값도 캔버스와 일치. 적용 한 번 및 Undo 한 번이 원문·모델에 동일하게 작동한다. 첫 사용자 두 흐름 검증. |
| 4. 센서 케이스 공유 치수 | 대기 | 폭이 다른 보드에 맞게 케이스를 바꾼다. | 56→64 mm에서 본체·뚜껑 64→72 mm, 오른쪽 고정점 2개 +8 mm. 왼쪽 고정점과 포트 크기 유지. 레시피 재열기 후 공유 관계가 살아 있고 CAD 출력도 실제 형상과 일치한다. |
| 5. 셀프센터링 바이스 | 대기 | 양쪽 조를 작업물 폭에 맞춘다. | 조/베이스 클릭은 부품 옵션, 간격 클릭은 조립 옵션. 40→60 mm에서 양쪽 조 −10/+10 mm, 작업 중심과 베이스 고정홀 유지. 나사의 동역학과 제조 검증은 범위 밖. |

각 단계에서 소스 테스트로 형상 치수와 고정값을 검증하고, 실제 브라우저에서 시작부터 저장까지 실행한다. 예제 사용자의 30초 목표는 직접 관찰하기 전까지 달성으로 표시하지 않는다.
