# Casual Studio 로드맵

[제품 설계](PRODUCT.md) · [진행 이슈 #749](https://github.com/barocss/cad/issues/749)

**목표:** 작은 CAD 모델을 예제에서 수정하거나 빈 코드에서 만들고, 모양뿐 아니라 편집할 수 있는 결과를 남긴다. 사용자 흐름을 하나씩 끝낸다. 검증이 끝난 시작 경로와 예제만 사용자에게 노출한다.

| 순서 | 상태 | 사용자가 끝낼 일 | 완료 기준 |
| --- | --- | --- | --- |
| 0. 독립 앱과 CAD 파일 왕복 | 완료 | 케이블 가이드 판의 지름 하나를 수정한다. | 실제 형상으로 A만 Ø6→Ø8, B Ø6·간격 30 mm 유지. 미리보기·적용·Undo/Redo·저장 및 CAD Studio 편집 후 Casual 재열기. |
| 1. 예제/파일 시작 화면 | 구현 완료 · 첫 사용자 검증 대기 | 예제를 골라 편집하거나 지원되는 내 파일을 연다. | 목적·결과·편집값을 먼저 제공. 예제 목록은 편집 중 숨김. 잘못된 파일·전환 취소 시 작업 유지. 데스크톱·좁은 화면 검증. |
| 2. 빈 코드에서 새 모델 만들기 | 완료 | 기존 판에 의존하지 않고 코드를 쓰거나 붙여넣어 내 장착판을 만든다. | 빈 캔버스에서 판과 위치/지름이 서로 다른 관통 홀 3개를 생성. 틀린 코드나 겹침은 마지막 적용 모델을 유지한다. 원문을 다시 열고 편집한 뒤 `.bcad`를 내보내 CAD Studio에서 진짜 피처로 열어 확인한다. Chrome에서 실제 빈 시작, 지름 3종, 오류 후 마지막 모델 유지, 레시피 재열기 및 CAD Studio 피처 수정 확인. |
| 3. 캔버스 ↔ 코드 공개 치수 | 구현 완료 · 첫 사용자 검증 대기 | 예제와 새 코드 모델을 같은 편집 공간에서 고친다. | 공개 파라미터만 캔버스에 노출하고 변경 시 해당 선언만 수정. 주석·다른 선언·피처 ID 유지. 코드 편집으로 바꾼 값도 캔버스와 일치. 적용 한 번 및 Undo 한 번이 원문·모델에 동일하게 작동한다. 케이블 가이드 예제와 새 코드 모델이 같은 편집기를 쓴다. 예제 기본값 복원은 미리보기·적용을 거치고 한 번으로 Undo된다. 첫 사용자 두 흐름은 관찰 대기. |
| 4. 센서 케이스 공유 치수 | 다음 | 폭이 다른 보드에 맞게 케이스를 바꾼다. | 56→64 mm에서 본체·뚜껑 64→72 mm, 오른쪽 고정점 2개 +8 mm. 왼쪽 고정점과 포트 크기 유지. 변경 부위별 전후 수치와 캔버스 강조를 연결하고, 위에서 보이지 않는 변화도 숫자로 안내한다. 레시피 재열기 후 공유 관계가 살아 있고 CAD 출력도 실제 형상과 일치한다. |
| 5. 셀프센터링 바이스 | 대기 | 양쪽 조를 작업물 폭에 맞춘다. | 조/베이스 클릭은 부품 옵션, 간격 클릭은 조립 옵션. 40→60 mm에서 양쪽 조 −10/+10 mm, 작업 중심과 베이스 고정홀 유지. 나사의 동역학과 제조 검증은 범위 밖. |

## 센서 케이스 구현 순서

1. **형상 먼저.** 보드의 왼쪽 기준과 포트 크기를 고정한다. 실제 native 본체·뚜껑·고정점을 만들고 두 유효 폭에서 실제 형상 치수를 측정한다. 아직 새 예제를 시작 화면에 넣지 않는다.
2. **한 번에 편집.** 보드 폭이 유일한 공유 입력이다. 유효 범위를 표시하고, 유효하지 않은 입력은 커밋이나 Undo 항목을 만들지 않는다. 미리보기에서 본체·뚜껑·고정점별 전후 값을 표시한다.
3. **파일까지.** 미리보기·적용·취소·Undo와 레시피 재열기를 동일한 모델로 검증한다. 내보낸 CAD에서 각 실제 형상과 보존된 관계를 확인한 뒤 시작 화면에 넣는다. native에서 유지되지 않는 관계는 명시한다.

## 다른 CAD에서 가져올 것

- **[OpenSCAD Customizer](https://en.wikibooks.org/wiki/OpenSCAD_User_Manual/Customizer#Syntax_support_for_generation_of_the_customization_form):** 선택한 값의 읽기 쉬운 이름·단위·허용 범위와 [기본값 복원](https://en.wikibooks.org/wiki/OpenSCAD_User_Manual/Customizer#GUI). 케이블 가이드의 복원은 반영했다. 치수 범위 표시를 센서 케이스에 확장하되 실제 형상에서 검증할 수 있는 제한만 보여준다. 복원도 검증·미리보기·적용을 거친다. 상시 설정 패널과 JSON 프리셋은 추가하지 않는다.
- **[Onshape Modeling In-Context](https://cad.onshape.com/help/Content/Assembly/modeling_in_context.htm):** 영향을 받는 부품 목록과 모델 강조를 연결한다. 센서 케이스에는 변경량이 적힌 짧은 목록을 두고, 마우스나 키보드 포커스로 해당 부품 또는 고정점을 표시한다. 외부 문서 참조·조립 컨텍스트 스냅샷은 도입하지 않는다.

각 단계에서 소스 테스트로 형상 치수와 고정값을 검증하고, 실제 브라우저에서 시작부터 저장까지 실행한다. 예제 사용자의 30초 목표는 직접 관찰하기 전까지 달성으로 표시하지 않는다.
