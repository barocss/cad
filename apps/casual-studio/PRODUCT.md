# Casual Studio 제품 기획 (#749)

## 어떤 일을 끝내는 도구인가

**이미 있는 설계를 내 부품에 맞춰 고치고, 다시 편집할 수 있는 CAD 파일을 가져간다.**
예를 들어 “기존 장비에 구멍을 더 뚫지 않고, 케이블 가이드를 30 mm 옆에 달고 싶다.”
이 사람에게 필요한 첫 화면은 스케치 도구 목록이 아니라, 목적과 결과를 설명하는 예제다.

- **Casual Studio**: 용도에 맞는 시작 모델을 고르고, 원하는 치수를 바꾸고, 달라진 것과 고정된 것을 확인한다.
- **CAD Studio**: 새로운 단면·피처를 설계하거나 원본 이력을 수정한다.
- **Viewer**: 변경하지 않고 검토한다.

화면과 초기 로드는 각자 갖되 CAD 엔진과 native `.bcad`를 공유한다. Casual을 쓰기 위해 코드나 CAD 명령을 배울 필요는 없다. 같은 파일을 Studio로 전달해도 피처가 메시로 바뀌지 않는다.

## 사용 흐름

1. **용도로 시작한다.** 시작 화면에 “기존 구멍을 써서 부품을 옆에 달기”처럼 결과가 보이는 예제를 둔다. 이름, 작은 결과 이미지, 바꿀 수 있는 값만 표시한다. 아직 동작하지 않는 예제를 만들 수 있는 것처럼 노출하지 않는다. 기존 파일 열기는 같은 시작 화면에서 가능하다.
2. **모델에서 고른다.** 기본은 캔버스, 부품 이름, 목적 한 줄이다. 구멍·부품·조립 치수를 선택하면 해당 옵션만 열린다. 예: 구멍을 고르면 지름, 간격 치수를 고르면 연결된 두 위치를 편집한다. 숫자 필드에는 단위와 편집 가능한 범위를 표시한다.
3. **변화를 확인한다.** 미리보기 중 원본은 바뀌지 않는다. 변경 전 경계와 영향받는 부위를 보여주고, 해당 모델에서 확인한 불변값을 짧게 표시한다. 겹침·범위 오류·모호한 선택은 적용하지 않고 다음 조작을 안내한다.
4. **적용하고 가져간다.** 적용 한 번은 Undo 한 번. 저장은 적용된 `.bcad`만 다운로드한다. 지원 밖의 구조 수정은 원본 파일을 그대로 유지하고 CAD Studio로 안내한다.

**코드**는 선택 사항이다. 데스크톱에서 열 때만 왼쪽에, 좁은 화면에서는 캔버스 아래에 둔다. 숫자 UI와 같은 변경 제안·미리보기·적용 경로를 쓴다. 채팅, 코드, 속성표를 한꺼번에 상시 띄우지 않는다.

## 출시 순서

진행 상태와 단계별 완료 조건은 [로드맵](ROADMAP.md)에서 관리한다.

처음 보는 사용자에게 **30초 안에 이 도구의 용도를 말하고 맞는 예제를 고를 수 있는지**, 그리고 **다른 구멍을 건드리지 않고 저장할 수 있는지**를 테스트한다. 이는 성공 기준이며 달성 결과가 아니다. 실패하면 도구를 추가하기보다 예제 이름·목적·선택 피드백부터 고친다.

범용 피처 트리, 채팅 모델 생성, 임의 코드 실행, 새 파일 형식, 제조 검증은 이 단계의 목표가 아니다.
